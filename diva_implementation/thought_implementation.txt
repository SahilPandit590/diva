2.2 Strict Inter-Engine Boundaries (Negative Constraints)
- Thoughts are NOT Actions: The Thought Engine develops hypotheses, explores consequences, and formulates candidate options; it NEVER triggers tool execution or external dialogue.
- Decisions Belong to Cognitive Integration: When a thought reaches a conclusion (e.g. "We should apologize to Alex"), it emits a proposal to Cognitive Integration. It cannot unilaterally commit Diva.
- Emotion Belongs to Emotion Engine: The Thought Engine does not set Diva's mood; it receives mood context and sends cognitive reframings.
- Motivation Belongs to Motivation Engine: The Thought Engine decomposes active goals; it cannot invent primary drives or motivations.
- Memory Belongs to Memory Engine: The Thought Engine maintains active reasoning context; long-term persistent storage is owned strictly by Memory.

4. THE SEVEN THOUGHT GENERATION PATHWAYS & AUTONOMOUS SCHEDULER
================================================================================

4.1 The Formal 3-Tier Cognitive Scheduler
Diva does not wait passively for a prompt. Her cognitive loop runs continuously under an adaptive 3-tier scheduler:

1. Reactive Execution (Immediate Event Priority):
   - Triggered instantaneously by high-priority `ThoughtPerceptionEnvelope` or acute emotional spikes.
   - Evaluates preemption against current focal thread in $<5\text{ms}$.
2. Periodic Cognition (Active Pacing: 50ms Tick):
   - Advances active focal reasoning chains, steps through sub-queries, and updates working memory context.
3. Autonomous Idle Drift (Idle Pacing: 500ms–2000ms Tick):
   - Operates when no user interaction occurs.
   - Paced by `InternalState.cognitive_energy`:
     * High Energy (0.8–1.0): Full speculative drift and deep counterfactual modeling.
     * Moderate Energy (0.4–0.7): Maintenance, consolidation reflection, and knowledge reconciliation.
     * Low Energy / Rest (0.1–0.3): Idle drift throttled; system enters cognitive rest.

4.2 Algorithmic Implementation of the 7 Pathways

1. Perceptual Ingress Pathway:
   Ingests normalized speech acts and ambiguity DAGs from Perception. If user asks a question or states a problem, spawns a `PROBLEM_SOLVING` thread.
2. Memory Spreading Activation Pathway:
   Queries Memory Engine for unintegrated episodes; recalls emotionally unresolved events and spawns retrospective inquiries.
3. Emotional Spike Pathway:
   Surges in curiosity, frustration, or affection inject direct attentional bias, compelling the Thought Engine to analyze the emotional cause.
4. Motivational Goal Pathway:
   Decomposes goals from the Motivation Engine into structured reasoning sub-goals (`UnresolvedQuestion`).
5. Counterfactual Exploration Pathway:
   Quarantined sandbox generator. Negates a known fact ("What if the user had stayed?") and projects alternative historical trajectories.
6. Spontaneous Associative Drift Pathway:
   Walks edges in the Semantic Knowledge Graph using biased random walks, connecting disparate concepts during quiet periods.
7. Meta-Cognitive Recursion Pathway:
   Monitors Diva's own thought chains; detects biases, circular arguments, or overconfidence, and generates corrective questions.

5. REASONING DAG, BRANCHING, MERGING & EPISTEMIC SEPARATION
================================================================================

5.1 The Reasoning Directed Acyclic Graph (DAG)
Reasoning is not a linear chain. It branches when multiple hypotheses exist and merges when evidence converges:

```mermaid
flowchart TD
    T0["Root Thought: 'Why did Alex sound upset today?'"] --> BranchFork{{"Hypothesis Branching Gate"}}
    
    BranchFork --> B1["Branch A (Work Stress)\nPremise: Alex mentioned deadline\nInductive Confidence: 0.65"]
    BranchFork --> B2["Branch B (Interpersonal Conflict)\nPremise: Diva made a blunt comment\nAbductive Confidence: 0.35"]

    B1 --> B1_1["Step A1: Retrieve past deadline episodes\nEvidence: Alex was terse on 3 past deadlines"]
    B2 --> B2_1["Step B1: Retrieve blunt comment episode\nEvidence: Alex laughed at the comment earlier"]

    B1_1 --> MergeNode{{"Reconciliation & Merge Node"}}
    B2_1 --> MergeNode

    MergeNode --> Conclusion["Synthesized Conclusion:\n'Alex is under deadline pressure, not angry with Diva.\nConfidence: 0.85 (Probable Conclusion)'"]
```

5.2 Branching & Merging Algorithms
- Branching Algorithm:
  When an abductive reasoning step produces $M \ge 2$ competing hypotheses with confidence margin $\Delta < 0.30$:
  1. The thread creates child branches: `Branch_A` and `Branch_B`.
  2. Each branch inherits the parent context but pursues its own evidence queries independently.
- Merging Algorithm:
  When evidence refutes one branch or when both branches reveal complementary facets:
  1. Synthesize a `MergeNode` thought instance.
  2. Map both branches to the merge node with relationships `RESOLVES` and `INTEGRATES`.
  3. Close child branches and resume the main thread.

5.3 Counterfactual Sandbox Quarantine
- Counterfactual simulations operate with `is_quarantined = True`.
- Invariant: A quarantined thought cannot write to the Memory Engine's Semantic or Fact tables, and cannot modify Diva's established belief state.
- When the simulation ends, it produces an `EVALUATION` thought summarizing the lesson learned, leaving the fictional premise discarded.

6. ATTENTION ARBITRATION, ANTI-MONOPOLIZATION & RUMINATION BREAKERS
================================================================================

6.1 Multi-Dimensional Dynamic Priority Formula
At each cognitive cycle, all candidate threads $k$ are scored:

$$P(k) = w_u \cdot U(k) + w_g \cdot G(k) + w_e \cdot E(k) + w_n \cdot N(k) - w_d \cdot D(k) - w_m \cdot M(k)$$

Where:
- $U(k)$: Urgency (time sensitivity).
- $G(k)$: Goal Relevance (alignment with Motivation Engine).
- $E(k)$: Emotional Salience (absolute affective intensity).
- $N(k)$: Novelty (unexplored ideas vs. familiar concepts).
- $D(k)$: Attentional Fatigue ($D(k) = 1.0 - e^{-\lambda \cdot t_{\text{elapsed}}}$).
- $M(k)$: Monopoly Penalty ($M(k) = \beta \cdot (\text{consecutive\_ticks} / 100)^2$).
- Weights: $w_u = 0.30, w_g = 0.25, w_e = 0.20, w_n = 0.15, w_d = 0.05, w_m = 0.05$.

6.2 Preemption & Suspension Gate
- If an incoming thread satisfies $P(k_{\text{new}}) > P(k_{\text{current}}) + 0.25$:
  1. Current active thread is cleanly suspended: `state = ThoughtState.SUSPENDED`.
  2. Context snapshot is persisted in SQLite checkpoint table.
  3. Thread $k_{\text{new}}$ is bound to `ActiveThoughtContext` and takes the focal spotlight.

6.3 Rumination Breaker & Monopolization Lockout
- Infinite loop detection: If the last 4 thoughts in a thread have semantic cosine similarity $> 0.88$ with no new conclusions or evidence:
  1. Trigger: `RUMINATION_DETECTED`.
  2. Transition thread to `SUSPENDED_RUMINATION`.
  3. Apply an attentional lockout timer of 15 minutes.
  4. Inject meta-thought: *"I am ruminating on this question without new evidence. Setting it aside until new information arrives."*

6.4 Resumption of Suspended and Abandoned Threads
- A suspended or abandoned thread is automatically re-evaluated and resumed if:
  1. An incoming perceptual event or memory recall matches the thread's `focal_entities` with semantic similarity $> 0.80$.
  2. The thread's urgency or goal relevance increases due to external changes.
  3. The rumination lockout timer expires and new evidence has become available.

8. MEMORY INTEGRATION, SELECTIVE ARCHIVING & SOVEREIGN RETENTION
================================================================================

8.1 Strict Decoupling of Completion from Archival
A completed thought thread does NOT automatically become a permanent memory. Most everyday thoughts are transient reasoning steps.

8.2 The Selective Archiving Gate
A completed thread is submitted to the Memory Engine for persistent retention ONLY if:
1. High Significance: Composite priority $P \ge 0.65$.
2. Epistemic Milestone: Establishes a verified novel belief, resolves an open contradiction, or forms an autobiographical self-realization (`ThoughtType.META_REFLECTION`).
3. Core Relationship Insight: Resolves an interpersonal uncertainty regarding a user.

8.3 Sovereign Memory Engine Authority
- The Thought Engine submits an archival package containing: the synthesized conclusion, the complete `ReasoningTrace`, constituent evidence IDs, and proposed categories (`AUTOBIOGRAPHICAL` or `SEMANTIC`).
- The Memory Engine retains absolute sovereign authority: it validates the proposal, checks against existing knowledge graphs, assigns retention tiers, and executes consolidation.

9.2 Restart Recovery Protocol
Upon startup:
1. `ThoughtLifecycleManager.initialize()` queries `thought_threads_checkpoint`.
2. Inspects elapsed time since `last_updated_at`:
   - If $\Delta t < 2\text{ hours}$: Restores active focal thread and pending queue directly into RAM; Diva resumes her exact train of thought.
   - If $\Delta t \ge 2\text{ hours}$: Marks previous active thread as `SUSPENDED`; initializes fresh focal context with acknowledgment: *"I was pondering X earlier; let me set that aside and see what's happening now."*

11. RESOURCE GOVERNANCE, ENERGY PACING & FAILURE MODES
================================================================================

11.1 Dynamic Energy Pacing
The Thought Engine dynamically adjusts its depth based on `InternalState.cognitive_energy`:
- Full Energy (0.8–1.0): Max 5 background incubating threads, full DAG branching, deep counterfactuals.
- Low Energy (0.2–0.4): Max 1 incubating thread, branching disabled, simple linear chains only.
- Exhaustion (<0.2): Pure reactive mode; all background threads suspended.

11.2 Graceful Degradation on Neural SLM Timeout
- Generative thought expansions are capped at a strict 400ms timeout on local hardware.
- If the neural model times out, the engine falls back to deterministic symbolic graph rules (NetworkX deduction) and flags `inference_degraded = True`.

- Turn 1: User says: *"I don't think I can do this project anymore."*
